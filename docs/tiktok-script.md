## טיפים לצילום

- **שוטים קצרים** — 2–4 שניות כל אחד. חיתוך על כל משפט.
- **זום במקום הסבר** — במסך המחשב, זום על המספר/הכפתור שמדברים עליו (ב־CapCut: "Zoom" או keyframes).
- **שוט 6–7 הוא השיא** — צלמו את הטלפון ואת המחשב בו־זמנית (טלפון שני מצלם את שניהם), כדי שיראו שהתיק נפתח "לבד".
- **מוזיקה:** ביט טכנולוגי שקט, עם "drop" בשוט 7.
- **כתוביות:** להשאיר את הטקסט במרכז־עליון של המסך, לא לכסות את הממשק.
- **נתונים:** לצילום אפשר להשתמש בנתוני הדמו שבמערכת (מאפיית השכונה, גולן אופניים…) — אחר כך מוחקים אותם בהגדרות. **לא לצלם** מפתחות מ־Supabase (עמוד API Keys) או פרטי לקוחות אמיתיים.
